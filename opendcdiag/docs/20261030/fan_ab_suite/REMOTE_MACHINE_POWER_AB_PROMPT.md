# 任务：本机复现"节点功率 ↔ SDC 率"交叉实验（参照第一台 SDC 机既定协议）

## 实验问题
第一台机观察到：SDC fail 率表观上与节点功率正相关（100% 风扇时节点功率更高 ~144W、fail 反而更多）。经两组对照已初步判定功率为伪相关，真调制者是缺陷核本座插槽温度（负相关，约每 +3.5°C 率减半）。本实验在本机检验三件事：
1. 现象（全速风扇臂功率更高且 fail 更多）是否复现；
2. 率差量级是否被温度曲线 2^(ΔT/3.5) 解释；
3. 功率是否存在超出温度预测的独立贡献。

## 阶段 0：前提核验（任何一步不成立则停下报告，不要硬跑）
1. **缺陷核**：本机 SDC 缺陷核编号、所在插槽及对应温度传感器名；确认该核 online。fail 必须全部归属该核，否则实验无意义。
2. **触发用例**：冒烟 15min 确认 ≥2 个高效用例在该缺陷核稳定触发（以 ≥30 fail/15min ≈ 2/min 为宜；最高只有 ~1/min 则把每臂延长到 30-45min）。优先试 `neon_rot_ldr_at_top_rowmajor` 家族（2 源 load + ALU 依赖链配方，跨机可移植）；不触发则用本机已登记的有效用例。**必须用 -O3 release 二进制**——第一台机实证 O0 编译产物使触发完全归零（四法交叉，P<10⁻⁴⁰⁰）；记录二进制 sha256。注意本仓 release 构建硬编码 -O3，属正常。
3. **风扇控制**：查明本机 BMC 手动/自动档命令（可设置、可回读验证）。第一台机为 ssh BMC + `ipmcset -d fanmode / fanlevel`，本机若不同先查清。
4. **温度通道**：ipmitool 定点读插槽级温度（无 per-core 温度）。
5. **功率通道**：BMC 节点功率传感器（W）。
6. **互斥**：实验期间停用 FARRON 等一切后台检测/负载系统。

## 阶段 1：风扇映射与安全红线（任何降档臂前必做）
- 单扇分组映射：哪只扇主控哪个插槽；各档位（100/60/40/20%）下最热插槽的预期温度。第一台机实证：某扇 40% → 对应插槽空载 102°C。
- 看门狗 95°C 自动杀测试并中止套件；**实验结束必须恢复风扇全速**（第一台机曾发生风扇死区停转热浸泡 104-106°C）。
- 换档时刻以**温度拐点**为准，不信 BMC 换档日志（第一台机实测其可滞后实际 ~12min）。

## 阶段 2：A/B 套件
- 每用例背靠背两臂（**同夜**，跨夜率有日尺度波动）：AUTO 风扇 15min → 手动全速 15min；若阶段 1 映射显示安全（最热插槽预估 <90°C），加测一档低臂，得 3 点剂量曲线更优。
- 掩码 = 缺陷核所在插槽全部核（含缺陷核）；`-n <显式核数>`（**禁 0**，0 被钳为 1）；`-T 15m --ignore-os-error --ignore-timeout`；auto seed（**永不固定 seed**）。
- 每臂采样（采样进程一律 taskset 钉离测试掩码）：插槽温度 30s；电压轨 + 节点功率 + 分插槽 CPU 占用 20s（用 `scripts/sdc_env_logger.sh`，仓库无则按此规范重写）。
- 每臂等稳态，统计取**最后 5 分钟均值**；臂间记录风扇档位与实际转速。
- 套件脚本 **setsid+nohup 脱离启动**，自带监控/看门狗/summary 落盘，可从孤儿 run 续跑。参考骨架：第一台机 `docs/20261030/fan_ab_suite/fan_ab_suite.sh`（注意其后台子 shell stdout 必须重定向，否则命令替换管道死锁）。
- **测试核独占铁律**：掩码上不得有任何其他负载；所有监控/分析命令钉离掩码；启动前核验无残留负载。

## 阶段 3：数据口径（与第一台机严格对齐）
- fail 计数 = 唯一 `result: fail` 块数（不是 grep miscompare，会双计 2 倍）；fail 块的 `cpu-mask` X 位置逐一验证归属缺陷核。
- 0-fail 臂须两法交叉（rc=pass + 无 miscompare）才算数。
- 记录 loops，/min 与 /loop 双口径同时给（两臂 loops 应接近；差异大说明时序受扰，须查明）。
- 分析三项：
  1. **臂内**：全速/AUTO 率比 vs 温度预测 2^(ΔT/3.5)；
  2. **恒功率**：挑节点功率相近（±2%）、温度不同的窗口，看率差是否随温度单调（第一台机：562-574W 内率差 5.4×）；
  3. **判据**：率比超出温度预测的部分 = 功率独立贡献。功率假说预测"同 ΔW → 同比率"；温度假说预测"随 ΔT 缩放"。
- 判读时注意诚实口径：风扇转速与温度反相关，本实验**不能**分离"温度 vs 风扇振动/EMI"（第一台机现状即二选一开放，唯一判别实验是恒定缺陷核插槽风扇档、只大幅切换其余扇的对照臂——若时间允许可加做）。
