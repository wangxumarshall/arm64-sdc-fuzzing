# CORE179 SDC 复现率 × 环境物理量轴关系汇总（温度 / 电压 / 频率 / 占用率 / 风扇转速）

**日期**：2026-10-30
**问题（用户）**：能否根据现有实验数据，汇总出 CPU 温度、CPU 电压、CPU 频率、CPU 占用率、风扇转速与 SDC 复现率的关系？
**数据基线**：2026-08-24（正向对照确立）至 2026-10-30（CPU4-only rowmajor 1h）全部可追溯落档战役；每条关系标注数据来源与**当前判决状态**（含被撤回的历史结论，防误引）。
**对象**：Kunpeng 920（4 路 192 核）179 号逻辑核（CPU4 插槽，核 144-191）的硬件 SDC 缺陷。**全部 fail 100% 锁 179**（历次战役无一例外），"率"即 179 的出错频率。

## 一、CPU 温度 → SDC 率（本档案最丰富的轴）

### 1.1 判决演化史（重要：防引用已撤回的中间结论）

### 1.3 决定性证据（10-27 勘误后）

1. **同温跨时段一致**：凉窗 C1（深夜）与 E（清晨）相隔 8.3h，率差 1.6%；热窗 A/B/D 跨整夜 1.78-2.81 一致。
2. **相邻 27min 窗即时翻转**：B→C1 随降温 2.10→12.96。
3. **520min 稳态基线两侧对称翻转**：D→E 降温 1min 内翻转，08:50-09:20 即达 13.6/min。
4. **换档台账 8/8 同向**（ΔT>1°C 的大幅换档全部率反向变化）。
5. **消歧检验**：吞吐归一化（块吞吐 479-575/min 全程平坦 → 非降频/跑慢伪影）；本座轴消歧（#13 CPU4=56.8°C 而 CPU2 凉，率 6.54 vs #8 CPU4=52.7°C，率 12.32 → 跟 179 本座温度，不跟全机热度）；热震荡役内 dT/dt 瞬态模型否定（稳定 1.51 / 升温 1.87 / 降温 1.62/min 无显著差异）。

### 1.4 机理候选与边界

- **机理候选①（温度说）**：时序裕量——冷硅晶体管路径更快 → str→ldr 转发窗口更紧 → L1D 读路径错更多。与触发配方对时序的极端敏感性自洽（nop≥8 灭活、编译期寻址模式/调度级敏感、-O 级别本身是检出开关）。
- **机理候选②（风扇耦合物理量）**：振动/气流——所有变温都经风扇实现，"凉=全扇 100%=振动最大"恰为高率窗。**与①不可分**，判别实验见 §二.4。
- **覆盖范围**：CPU4 51-65°C；<45°C 无数据（CPU4 空载地板 47-48°C，本机不可测）；63.7°C 为持续上限；响应延迟分钟级（64→54 约 1-3min）。
- 旁证：10-29 电压实验中 SDC 时刻 CPU4_TEMP 分位 0.31（略偏凉侧，同向）；FARRON 评估期 54-63°C 恒风扇窄带内率平坦（与响应曲线带内斜率及窗自热混淆一致）；neon168 稳态 53-55°C 出史上最高持续率 15.4/min、10-30 CPU4-only 53.4°C 出第二高 14.75/min（均在凉带）。
- 文献对照：CACM 2026-09 综述——温度是典型 SDC 触发条件，方向不可直觉预判。

## 二、风扇转速 → SDC 率

### 2.1 风扇-插槽映射（12 档稳态矩阵实测）

| 风扇 | 主责插槽 | 单扇降档代价（100%→40% 温升） | 对 179 的作用 |
|---|---|---|---|
| F1 | 无主责 | 0°C（完全冗余） | 无 |
| F2 | CPU3 | +5.3°C（全机最关键单扇） | 无 |
| F3 / F4 | CPU2（对称各半） | +3.0 / +3.1°C | 无 |
| **F5** | **CPU4（独占）** | **+3.8°C** | **唯一有效旋钮** |
| F6 | CPU1 | +3.0°C | 无 |

duty→转速：40%≈7.4-8.1k，60%≈11.5-12.1k，80%≈15.5-15.9k，100%≈19.4-20.2k RPM（F5=20%≈3.8k）。

### 2.2 F5 剂量 → 温度 → 率（风扇作用全部经温度实现）

F5 100%→CPU4 52.7°C / 40%→61.4 / 20%→63.7（CPU4-only 干净构型）。混合负载下 F5=20 被其余风扇抵消 2-3°C，未达剂量上限。**除 F5 外任一单扇降档，CPU4 钉在 52-53°C、率全部落凉带散布内（8.81-12.32/min），无一致响应**（表 D 五次实测）——单扇不是 179 的旋钮。

### 2.3 判决

- **风扇对 SDC 率没有证据支持独立（不经温度的）作用**；本机上"调风扇"与"调温度"是同一操作的两面。
- 表 D 五次单扇换档（振动变化不小、温度不动）无一致率响应——**轻微不利于振动说**，但单扇振动增量不足以定案。
- 历史上风扇曾两度"事故性充当开关"：CPU2 过热看门狗中止战役（F5 与 CPU2 共享风道，#14 极限档 CPU2 70→98°C 仅 <5min）——这是**数据损失**而非率响应。

### 2.4 安全红线（动风扇必读）

F6=40 → CPU1 纯空载 102°C；F5 压低必配 F3-4=100；CPU4-only + F5=20 + 其余 100% = 唯一干净加热构型；降风实验收工前必须先恢复风扇（死区 CPU2 曾热浸泡 104-106°C）。

### 2.5 判别实验（未跑，是温度轴的收尾）

**振动对照臂**：恒 F5=20（CPU4 钉 63.7°C），仅切换 F1-2/F3-4 于 100↔40 间大幅变化（转速大变、CPU4 仅 ±1.5-2.6°C）——**率跟转速走 → 振动说；率不动 → 温度说定案**。辅臂：F5 在 52.7↔61.4/63.7 间随机交错 ≥4 轮复现五窗关系。

## 三、CPU 电压 → SDC 率：排除

**实验**（10-29，首次启用 BMC 电压传感器，~1s 采样 / 10mV 分辨率）：CPU4-only neon 负载 600s 窗内 73 个 SDC 事件（7.3/min），fail 块 UTC 时间戳与最近电压样本配对（72/73 有样本）。

| 轨 | 空载 | 负载期 | SDC 时刻 | 判定 |
|---|---|---|---|---|
| 主核轨 N_VDDAVS_CPU4 | 0.960V | 0.960V（std 0.0016） | **72/72 全 0.960V** | 无偏低、无压降 |
| 副轨 CPU4 VDDAVS | 0.877V | 0.847V（负载压降 -30mV，0.82-0.87 波动） | 0.850V，**分布与负载期几乎重合** | 不偏好低压时刻 |

- **判决**：BMC 可观测尺度（轨级、秒级、10mV）上，**供电电压轴排除**。若缺陷为 Vmin 边际型（供电不足致锁存错），SDC 应聚集低压时刻——该信号 absent。
- **10-30 复证**：rowmajor 1h，269 个落窗 fail 时刻核轨 0.960V×262 / 0.970V×7（出现率与全程无差异），功率均值 707W=全程均值——无电压塌陷、无功率异常。
- **诚实边界**：µs 级 di/dt droop 毛刺物理不可测（需板级示波器，本机无通道）；本机无 DVFS → 电压轴天然缺乏变异，"恒压 + SDC 照发"本身就是信息：**供电水平不是调制因子**。

## 四、CPU 频率 → SDC 率：无信息（排除 confound）

- **本机无任何 OS DVFS**：固件未提供 `_CPC`/`PCCT`，`cppc_cpufreq` 拒载；**恒 2.6GHz**（dmidecode 2600，PMU 实测忙核 2.598-2.599GHz）。查看唯一通道=忙核 PMU cycles（空闲核时钟门控停表）；BMC 无频率传感器；ARM64 无 thermal_throttle sysfs。
- **唯一降频机制 = PROCHOT 硬件热跳闸（~105°C 内部）**：per-socket 时钟门控级停摆（迭代 1.4s→22s，非温和降频），bang-bang+迟滞，解除即完全恢复。6 个确认窗口（10/14-15）**全部在 CPU1**（热事件 96 条全 CPU1）；**CPU4/179 从未降频**（本座最凉，零事件）。
- **对 SDC 率的含义**：179 的全部 SDC 数据产生于恒定 2.6GHz——频率轴没有变异，无法也无需调制率。交叉证据：CPU1 降频期间 179 照常出 fail（9/44 fail 落断言段内），降频期率 1.07 vs 干净期 0.99/min 无差别；温度战役块吞吐 479-575/min 全程平坦（率变化非降频伪影）。
- **结论**：频率轴对 179 的 SDC 率**无信息**；其价值在于把"率差异"与"频率差异"解耦（任何率变化都不能归于降频）。

## 五、CPU 占用率 → SDC 率：结构条件，非率的单调调节器

占用率回答的是"**能不能触发**"（必要条件、结构性），而不是"触发多快"。历次收窄如下：

### 5.1 触发的结构必要条件（从全机收窄到插槽/进程级）

| 负载结构 | 率（fail/min） | 含义 |
|---|---|---|
| 全机 168 核（neon168） | 15.4 | 历史最高持续率 |
| **CPU4-only 48 核（含 179）** | **14.9** | **插槽自足：其他 144 核空载率不降** |
| 混合 72 movbe + 96 neon | 6-12.7（漂移） | 干净核对照零错 |
| 179 独立进程 + 164 核背景 | 1.57 | 同进程 vs 独立进程差 ~10× |

- 08-24 正向对照确立"触发=系统级全核并发压力"（且推翻 dormant 假说：全核+auto seed）；**10-25 收窄为插槽/进程级**——只需 179 + 同插槽同测试兄弟线程（单进程），全机并发压力并非必要。
- **同进程共振候选**（未定）：179 在进程内 vs 独立进程率差 ~10×，与热震荡役"同测试共振"子假说同族。

### 5.2 占用率的"类型"比"量"重要（二元门控）

热震荡役（10-23，等时长等迭代暴露）：背景 **movbe 0/14796 迭代 vs 背景 neon 47/14764（p≈1.4e-14）**，逐相位 6 轮无一例外。触发跟随负载切换的瞬时沿而非温度（事件 23 在切换后 1s @51.2°C——该温度正是 movbe 相位平台温度，而 movbe 下 30min 零触发）。子假说未分：负载类（NEON 向量访存 vs movbe ~31% duty 标量访存）vs 同测试共振（165 份同足迹进程）；设计缺口=无"空背景"对照臂。

### 5.3 跨槽占用率与编译结构压倒占用率本身

- **跨槽占用率无关**：同温（53.4 vs 53.5°C）下 CPU4-only 较全掩码 168 核 fails/min **+10.6%**——去掉 144 核负载不降率（反而略升，机制不解读）。
- **编译轴是更强的开关**（10-30 O0/O3 同晚同掩码同负载结构）：O3 臂 752 fail（rowmajor 13.33、mrn 7.80、movbe 1.93/min 及部分窗 3.8-8.85）vs **O0 臂五用例全零**（四法交叉验证，P<10⁻⁴⁰⁰）；同日午后在 CPU4-only 标准采样构型（48 核含 179）复验：O0 rowmajor 1h 仍全零（2930 loops@1228.34ms 满工作量，CPU4 反热 55.7°C，温度校正后 P(0)≈10⁻²⁴⁴），配对同协议 O3 臂 885f/14.75/min——"编译产物=检出开关"跨掩码构型一致（`docs/20261030/cpu4_rowmajor_1h_O0/RESULTS.md`）。O0 臂迭代反而多 12-15%、温度反热 2-3°C（按温度梯度最多解释 ~2×，无法解释归零）——**同为满占用，率可以是 0**：占用率不是充分条件，指令/时序结构才是触发开关。
- **归一化口径**：跨负载比较须用 fail/千迭代块（movbe 仅 ~31% duty，纯时间归一化会失真）；本机吞吐恒定（479-575 块/min）使 fail/min 与 fail/千块等价。

### 5.4 生产形态验证（占用率现实约束下检出率 100%）

FARRON 生产节奏验收（6h，每 30min 一轮 30s 插槽窗）：**12/12 轮全检出**（21 fail 全 179，36 个干净插座窗零误报）；应用吞吐损失仅 **1.815%**，FARRON 自身消耗 0.88%（背靠背 stress-ng 对照形态为 13.3%，干净窗占空 37% 系 fracture 分段机制）。**检出只取决于"进入缺陷插槽的 30s 窗"**——率的高低由温度轴决定，检出与否由结构条件决定。

### 5.5 占用率的两条间接路径（已消歧）

1. 占用率 → 温度：neon 相位比 movbe 热 ~2°C（热震荡役表观 r=+0.49 系共线，已由本座轴消歧拆开）。
2. 占用率 → 降频：仅 >105°C PROCHOT 才发生，且只影响超限插槽，与 179 率无关（§四）。

## 六、轴间混淆矩阵与消歧方法（方法论沉淀）

| 混淆对 | 消歧手段 | 结果 |
|---|---|---|
| 温度 ↔ 风扇振动/气流 | 单扇换档臂（表 D）；振动对照臂（待跑） | 弱证据偏温度；未定案 |
| 温度 ↔ 负载类型 | 相位内裁剪窗 + 零热滞后检验 + 静态阈值夹杀 | 热震荡役内温度否定（门控=负载类型）；跨役温度成立（带外有梯度）——**两个结论不矛盾：役内带宽不足，役间已补** |
| 温度 ↔ 全机热度 | 本座轴对照（#13 vs #8：CPU2 同凉率差 1.9×） | 跟 179 本座（CPU4）温度 |
| 温度 ↔ 吞吐/降频 | 块吞吐平坦 479-575/min；PROCHOT 期率不变 | 非吞吐伪影 |
| 温度 ↔ 相位/时序（爆发周期） | 五窗结构（同温 8.3h 一致 + 27min 即翻 + 520min 稳态对称翻转） | 相位说排除 |
| 电压 ↔ 负载 | SDC 时刻分布 vs 负载期分布直方图 | 无低偏 |
| 占用率 ↔ 代码结构 | O0/O3 同占用率对照 | 编译/结构轴独立于占用率 |

**率的横切注意事项**：
1. 179 存在爆发/潜伏时间结构（爆发 ~35min、峰值可达潜伏基线 ~7×；恒温带内 10min 粒度散布 ~2.3×）——温度调制的是**基线/包络**，爆发幅度是否随温度台阶即时缩放是判别实验的观测项之一。
2. **单 10min 窗口率不可比**；跨配置比较需 ≥1h 或多窗口交替。
3. 事件时刻一律用失败块 `[time-at-start, time-at-end]` 窗口（`time-to-fail` 字段非墙钟，重分析法曾产生 5 个伪事件）。

## 七、未闭环项清单（按优先级）

1. **温度 vs 振动判别实验**（温度轴定案的最后一步）：恒 F5=20 钉 63.7°C，切换 F1-4 转速 100↔40——率跟转速走→振动说；不动→温度说定案。基础设施现成。
2. **F5 随机交错复现**：52.7↔61.4/63.7 随机切换 ≥4 轮，检验段内基线是否跟温度走。
3. **<45°C 不可达**：CPU4 空载地板 47-48°C，真低温无数据（无法本机解决，只能换环境）。
4. **µs 级 di/dt droop**：BMC 通道物理不可测（需板级示波器）——电压轴的永久残留。
5. **负载类 vs 同测试共振**：等温异构背景（neon_rot vs k7p_rand/arm0102_kreg_mask）、探针对调、空背景臂。
6. **同进程共振 ~10× 的归因**（1.57 vs 14.9/min）。
7. **编译轴收窄**：-O1/-O2 梯度或同参数重建 -O3，把"-O 级别本身是开关"收窄到具体代码产物差异（objdump 邻域对比已 designated）。
8. **爆发幅度 × 温度台阶**的交互关系。
