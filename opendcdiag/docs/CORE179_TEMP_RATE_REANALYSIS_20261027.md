# CORE179 温度-SDC 率再分析：风扇战役数据重算与判决修正（2026-10-27）

**问题（用户）**：全核混合负载+人工调风扇的战役里，高温时的 SDC 数量能否算出频率？是否存在低温率高、高温率低？
**结论先行（2026-10-27 晚修订）**：三组温度干颂数据**同现汇总负关联**（CPU4 越高率越低），10-24 混合战役通过吞吐归一化、本座轴消歧、换档响应三重检验；**换档时刻经温度拐点校正后，CPU4-only 战役还原为五窗 A/B/C1/D/E**——同温跨 8.3h 率一致（12.96/13.17/min）、相邻 27min 窗随降温即翻（2.10→12.96）、8.3h 稳态基线两侧对称翻转——**相位/时序解释被排除**。**判决：温度（或风扇耦合物理量）强因果调制 179 SDC 基线率**（52-53°C ~13/min·23.0/千块 vs 61-64°C ~1.8-2.8/min·3.1-5.0/千块）；剩余唯一混淆=温度与振动/气流的分辨，待振动对照臂实验（§五）。
**此前判决为何失效**：①"终审证伪"的 11°C 台阶在 CPU2 轴（179 不在那里）；②热震荡战役带内仅 1°C，对 ~1.5×/4°C 的效应不敏感；③09-11 实验判伪象的三条理由（轮首瞬态/单轮爆发/跨条件波动）均不适用于 10-24 连续无轮数据。

## 四、解释格局（2026-10-27 晚更新）

- **温度说**：基线率随 CPU4 温度单调降（约每 +3.5°C 减半）。机理候选自洽：时序裕量——冷硅路径更快 → str→ldr 转发窗口更紧（触发配方对时序极端敏感：nop≥8 灭活、布局敏感）。
- **相位/时序说**：已被五窗对照**排除**（§三：同温跨 8.3h 一致 + 相邻窗即时翻转 + 520min 稳态基线两侧对称翻转）。
- **风扇耦合说（剩余唯一混淆）**：所有变温均经风扇实现——凉窗=全扇 100%（振动/气流最大）恰为高率窗，两说方向均符合；混合役 #8-#12 五次单扇换档（振动变化不小、CPU4 不动）无一致率响应，轻微不利于振动说，但不足以定案。**温度 vs 振动/气流需振动对照臂分离（§五）。**

## 五、判别实验设计（基础设施现成）

- **负载**：CPU4-only neon48（持续，块率平坦已证）；**保护**：F3-4/F6=100（钉住 CPU2/CPU1），F5 走剂量曲线 100/40/20%（CPU4 52.7/61.4/63.7°C）。
- **设计**：F5 在 52.7↔61.4（或 63.7）之间**随机交错**切换，每条件 ≥1h，≥4 轮交替；判据=①段间基线是否跟温度走（相位说下会看到条件内基线漂移与温度无关）②爆发幅度是否在台阶处即时缩放。
- **振动对照臂**（剥离风扇混淆）：恒 F5，改 F1-2/F3-4（转速大变、CPU4 仅 −1.5~−2.6°C）——率跟 F5 走不跟 F1-4 走 → 倾向温度；率跟转速走 → 振动/气流。
- 须全程记录频率/功耗协变量；看门狗在岗（F5=20 时 CPU2 共享风道会升温）。

## 七、修正后的结论（取代旧判决）

1. **实测可答用户问题**：高温时率可计算——混合战役 CPU4≥56°C 段 7.1-7.7/min（12.0-15.4/千块），CPU4-only 61-65°C 段 1.5-3.5/min；低温端 52-53°C 段 11.6-13.4/min（17.9-28.1/千块）。
2. **汇总负关联三重复现、过归一化与本座轴检验**——"温度无关"的旧判决**证据不足，予以撤销**。
3. **因果判决升级（10-27 晚）**：相位/时序解释排除；**温度（或风扇耦合物理量）强因果调制基线率**，剩余混淆=温度与振动/气流的二选一，振动对照臂可分离。
4. 效应量（若为温度）：~1.5-1.7×/4°C（52-57°C 带内）；CPU4-only 的 7× 汇总梯度中相位混叠贡献未知比例。
5. **范围**：CPU4 51-65°C；绝对低温（<45°C）无数据；>63.7°C 为本机 CPU4 可持续上限。

**数据与复现**：本文全部数字由 `run1_neon96.log`/`neon96.log`/`cpu4only_cont_fan5040/run.log` 的块级 `now` 时间戳与 `temp_5s.log` 5s 温度直接计算；提取方法见 §一。
