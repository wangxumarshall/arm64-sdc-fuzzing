  | unaligned | 0 ✅ | 0 | — | 0 |
- 三个结论：

  3. unaligned 0-fail ≠ "对齐才触发"，而是改寻址改布局 → 窗口被挪走（布局敏感性再证）

### 第 10 页：SIMD 实验设计
- 关键设计选择（重点框）：
  - 用 uint64x2_t（2-lane 64-bit），vaddq/veorq/vandq/vorrq_u64 每 lane 语义与标量版完全同构 → "标量 ALU → NEON 单元"是唯一变量
- 热循环代码块（与第 4 页标量骨架并排对照，突出逐项对应）：
  ```
  a = srcA[i]          ; ldr q (vector load A)
  b = srcB[i]          ; ldr q (vector load B)
  res = NEON轮换(a,b)  ; vaddq/veorq/vandq/vorrq
  str q [temp[i]]      ; vst1q
  ldr q [temp[i]]      ; asm 保证背靠背 reload
  str q [dst[i]]
  ```
- 工程坑提示框（橙色边框）：NEON intrinsic reload 会被 GCC 消除（objdump 实证无 ldr 发出）——reload 必须走 __asm__ volatile；修复后 objdump 验证 str q→ldr q 背靠背落进二进制

### 第 11 页：SIMD 实验结果
- 两阶段结果：
  - 阶段 1（排除 179，60s）：0 fail ✅
  - 阶段 2（全核 192 含 179，30min）：**33 个唯一 fail 块，全 thread 179**，首触发仅 11.6 秒，33 个独立 seed
- 对比表格（本页核心，大数字）：
  | 指标 | NEON 版 | 标量基准 (agu_stress_2src) |
  |---|---|---|
  | fail 块 / 30min | **33** | 19 |
  | 触发率 | **~1.1/min** | ~0.63/min |
  | **触发率比** | **1.7 倍** | 1.0 |
- 结论要点：
  1. **配方不绑定标量通路**——NEON 向量通路同样触发
  2. "SIMD 是 SDC 多发区"在 179 获得首个受控实证；NEON 版成为**触发率最高的受控检测器**
  3. 关键在数据流模式（多源 load→轮换 ALU→紧邻 reload），非特定执行单元
