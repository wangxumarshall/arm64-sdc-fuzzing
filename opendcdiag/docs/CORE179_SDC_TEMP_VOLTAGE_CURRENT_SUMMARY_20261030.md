# 本机 SDC × 温度 / 电压 / 电流（功率）研究总结报告（截至 2026-10-30）

> **范围**：CORE179（鲲鹏 920，192 核 4 插槽；缺陷核 179 位于 CPU4=cores 144-191）在本机上关于物理环境量与 SDC 检出率关系的全部实验、结论及其演化。
> **上游专档**：温度 living 登记册 `docs/CORE179_TEMPERATURE_RESEARCH_20261027.md`（表 A-E 权威数据）；电压实验 `docs/CORE179_VOLTAGE_AT_SDC_20261029.md`。
> **三轴一句话**：**温度=强因果调制（负向，~4.6-7.4×）；电压（缓变）=已排除；电流/功率=已排除**。µs 级电压瞬态与"温度 vs 风扇振动"为两大未决残留。

---

## 一、测量通道建设（一切结论的前提）

| 量 | 通道 | 关键事实 |
|---|---|---|
| **温度** | BMC/IPMI 插槽级（`sudo ipmitool sensor reading`，~0.8s/次；全表 15.7s） | 唯一通道；仅 4 个插槽传感器（CPU1=0-47 … CPU4=144-191）；无 per-core；179=CPU4_TEMP；OS 侧 thermal sysfs 在 ARM64 不存在 |
| **频率** | 无 OS DVFS（无 _CPC/PCCT，恒 2.6GHz）；忙核 PMU cycles | **CPU4/179 从未降频** → 179 全部数据无频率混淆；BMC 无频率传感器 |
| **风扇** | BMC SSH（9.3.12.13）`ipmcset -d fanmode/fanlevel` | 手动档+定时自动恢复（当前长期 99999s+100%）；duty→转速：40%≈7.4-8.1k / 60%≈11.5-12.1k / 80%≈15.5-15.9k / 100%≈19.4-20.2k RPM |
| **电压** | BMC 电压传感器（10-29 首次启用） | 核轨 N_VDDAVS_CPU1-4（~0.94-0.97V）、副轨 CPUx VDDAVS（~0.84-0.88V）、HVCC 1.20V、VDDQ 1.21V、DDR_VDD/VDDFIX 0.80V、PS2 VIN 224V、12V×5 |
| **电流** | **无传感器**（`sdr type current` 为空、DCMI 不支持） | 以 **Power/Power2（W）为代理**（兼作风扇态/负载态佐证） |
| **通道勘误** | 多词传感器名（"CPU4 VDDAVS"）定点读 ~5s、大混批超时；单批读法要点见记忆 | 曾致监控风扇字段长期为空（初判"并发撞"有误，已修正） |

**平台热学事实**：CPU4 全机散热最好（同负载比 CPU2 低 ~20°C）；空载 47-48°C=实验下限；持续上限 63.7°C（F5=20%）；热时间常数：负载 τ≈60-90s、换档分钟级；CPU2 为散热短板（手动档下全核负载 54s 冲 96°C，98°C 仅 20-110s，PROCHOT 震荡 83↔103°C）。

## 二、温度轴（研究最深，结论三阶段演化）

### 2.1 演化时间线

| 阶段 | 时间 | 实验 | 当时的判断 |
|---|---|---|---|
| ① 负相关初现 | 09-11 | 风扇干预（CPU4 45-73°C） | pooled **r=-0.92 负相关**，因相位混淆判"伪象"；当天 5 次重启 3 次发生在最凉条件 |
| ② 机制澄清 | 10-16 | PROCHOT 降频实证 | 降频=per-socket 时钟门控近停摆（迭代 1.4s→22s），但 **179 降频期 fail 率不变（1.07 vs 0.99/min）**；CPU4/179 从未降频 → 频率/降频伪影排除 |
| ③ 热画像 | 10-23~24 | neon168 满载 / 热震荡 / 风扇分区测绘 | CPU4 满载达不到 70°C；**53-55°C 稳态下 15.4/min 史上最高持续率**（凉端高速率首个强信号）；风扇效率图谱落档 |
| ④ 判决升级 | 10-27 | 混合扫描 + CPU4-only 五窗重算 | **相位说排除，判决=温度（或风扇耦合物理量）强因果调制基线率**；旧判"温度无关"撤销改"强因果" |
| ⑤ 一致性复现 | 10-30 | CPU4-only rowmajor 1h @53.4°C | **14.75/min**，与 10-27 的 53°C 档（12.96-13.17/min）吻合 |

### 2.2 核心数据：179 温度-SDC 率响应曲线（10-24/25 两战役合并，10-27 专档表 C）

| CPU4 °C | SDC 率/min | fail/千块 | 来源窗 |
|---|---|---|---|
| 52-53.1 | **12.96-13.17** | 22.9-23.2 | CPU4-only（两窗相隔 **8.3h 率一致**） |
| 52.2-54.2 | 8.81-14.44 | 17.9-28.1 | 混合负载 8 段 |
| 55.5-57.2 | 5.75-9.41 | 12.0-18.5 | 混合负载 4 段（56.7°C 恒温 5.5h） |
| 61.7 | **2.81** | 5.03 | CPU4-only A |
| 63.4 | **2.10** | 3.66 | CPU4-only B |
| 63.9 | **1.78**（520min 稳定） | 3.10 | CPU4-only D |

- **特征**：单调下降，**约每 +3.5°C 率减半**（13→7.7@56.7→~2@63.4）；响应延迟分钟级
- **因果强度证据**（10-27 专档表 E）：全部 8 次 ΔT>1°C 换档 **8/8 同向**；相邻 27min 窗随降温即翻（2.10→12.96）；8.3h 稳态基线两侧对称翻转（1.78↔13.17，64→54°C 仅 1min）——"活跃相位恰好在每次换档时刻翻转 8 次"不可信 → **相位/时序解释排除**
- **换档时刻校正教训**：FAN_CHANGE 记录滞后实际换档 ~12min——一切换档分析以**温度曲线/功耗拐点**为准（v1 的"爆发跨 11°C 不增幅"反例即此误判，已撤销）

### 2.3 风扇作为温度旋钮（10-27 专档表 A）

六扇分工：**F5=CPU4 唯一有效旋钮**（100→40% = +3.8°C，独占）；F2=CPU3（+5.3°C 全机最关键单扇）；F3/F4=CPU2（+3.0/3.1）；F6=CPU1（+3.0，F6=40 时空载 102°C 红线）；F1 完全冗余。非 F5 单扇换档（表 D 五次，振动变化不小而 CPU4 钉 52-53°C）率全部落在凉带散布内——无独立作用。

### 2.4 已排除的混淆（汇总）

相位/时序（表 E-6/7/8）；吞吐/降频（两役块吞吐 479-575/min 全平坦 + PROCHOT 期率不变）；负载类型门控（两役负载恒定）；机位热度（CPU2 同凉消歧，率差 1.9×）；供电电压（见 §三）。

### 2.5 当前判决与剩余混淆

**判决：179 SDC 基线率严格跟随其本座（CPU4）温度，单调负相关，~4.6-7.4× 调制幅度。**
**唯一剩余混淆 = 温度与风扇耦合物理量（振动/气流/声学）的分辨**——所有变温都经风扇实现，凉窗=全扇 100%（振动最大）恰为高率窗。弱分离证据（表 D）轻微不利于振动说但不足定案。
**判别实验（已设计未跑）**：CPU4-only 恒 F5=20（CPU4 钉 63.7°C），仅切换 F1-2/F3-4 在 100↔40 大幅变化——**率跟转速走→振动说；率不动→温度说定案**。

### 2.6 温度轴的边界（与编译开关的关系，10-30 新增）

温度调制的是"率"而非"存在"：10-30 配对实验中 **-O0 臂在比 -O3 臂更热 2.3°C 的条件下（55.7 vs 53.4°C）依然零检出**（885 vs 0 fail，e⁻⁸⁸⁵）——温度梯度（≤2×）远不足以解释编译产物开关（0/∞）。两轴正交：编译产物决定缺陷是否表达，温度调制表达时的率。

## 三、电压轴

### 3.1 直接实验（2026-10-29，`docs/CORE179_VOLTAGE_AT_SDC_20261029.md`）

- **73 个 SDC 时刻**的电压分布分析：**主核轨（N_VDDAVS）恒 0.96V 无压降**；副轨（VDDAVS）负载期降 ~30mV 但 **SDC 时刻分布与负载期完全重合**（不偏好低压时刻）
- **判决：供电电压缓变轴排除**；µs 级瞬态 droop 为 BMC 采样（秒级）物理不可测残留
- 附带教训：手动风扇档下全核负载 CPU2 54s 冲 96°C

### 3.2 SDC 时刻电压记录常设化（2026-10-30 用户指令）

协议：所有率测量类 run 并行 timestamped 电压/功率采样器（快组 ~4-8s：四路核轨+功率；慢组：副轨/HVCC），分析时 fail 块时间戳（UTC+8h）对齐最近邻样本。

**首轮数据（10-30 上午 CPU4-only rowmajor，885 fail 中 269 个落电压窗，≤10s 对齐）**：

| 项 | 全程分布 | fail 时刻 |
|---|---|---|
| N_VDDAVS_CPU4 | 0.960V×124 / 0.970V×3 | 0.960V×262 / 0.970V×7（0.970 出现率 2.4% vs 2.6%，无差异） |
| Power（电流代理） | 678-744W，均值 707W | **均值 707W = 全程均值** |

**-O0 配对臂全程**（408 样本）：主轨 0.960V 平坦（399/408）；**副轨 CPU4 VDDAVS 均值 0.844V**（0.84×111 / 0.85×34 / 0.86×8 / 0.87×3；比 10-29 负载期 0.847V 低 3mV、与功耗 +8W 同向；无 <0.84V 样本）；HVCC 恒 1.200V。

**判决：10s 分辨率下 SDC 时刻无电压塌陷、无功率异常**——与 10-29 排除结论一致。

## 四、电流/功率轴

- **通道现状**：本机 BMC 无电流传感器（`sdr type current` 空、DCMI 不支持）——电流为**不可直接测量**，Power/Power2（W）做代理
- **功耗与 SDC 的实证**（10-30 配对）：-O3 臂 707W / 885 fail vs -O0 臂 715W / 0 fail——**功耗不调制率**（且方向反向：更耗电的臂零检出）
- **功耗的辅助用途**：风扇态/负载态佐证（温度专档表 B1：低档 562-574W vs 全扇 704-710W；换档时刻以功耗拐点校正）
- 附带观察（昨夜）：-O3 构建的 sub/str3 热稳态 >95°C vs -O0 同用例仅 76-83°C——**二进制臂间存在功耗/吞吐差异**，做温度敏感实验时须固定二进制

## 五、三轴综合图景

| 轴 | 关联方向 | 强度 | 状态 |
|---|---|---|---|
| 温度（CPU4 本座） | **负**（越热率越低） | 4.6-7.4×，每 +3.5°C 减半 | **强因果**（剩余混淆：振动） |
| 电压（缓变，秒级采样） | 无 | — | **排除**（73+269 个 SDC 时刻无异常） |
| 电流/功率 | 无 | — | **排除**（配对臂反向） |

**机理候选（温度轴，二选一未定）**：
1. **硅温度直接调制**——时序裕量假说：冷硅路径更快 → str→ldr 转发窗更紧 → L1D 读路径错更多；与触发配方对时序的极端敏感性自洽（nop≥8 灭活、编译布局敏感、-O0 归零）
2. **风扇耦合物理量**（振动/气流/声学）——凉窗=全扇 100% 恰为高率窗；与 09-11"重启 3/5 在最凉条件"同向

**层级关系**：编译产物（-O0/-O3）= 表达开关（0/∞）＞ 温度 = 率调制（~5×）＞ 电压/功率 = 无关。文献对照（CACM 2026-09 综述）：温度是典型触发条件且方向不可直觉预判——本机负向不孤立。

**生产化落地**：FARRON 在线健康管理系统（farron/）的温度控制器（过半超界升界/仅 tail 超界降载）直接建立在本温度轴发现上。

## 六、方法论沉淀（协议清单）

1. 监控绑核 0 或 8（掩码外、离 179）；看门狗 95°C（热实验 98°C×2）
2. **换档时刻以温度/功耗拐点为准**（FAN_CHANGE 滞后 12min）；每档等 ≥10min 取末 5min 稳态
3. 风扇安全红线：F6=40 前必查 CPU1（空载 102°C 先例）；F5 压低必配 F3-4=100；CPU4-only+F5=20+其余 100 = 唯一干净加热构型；**收工先恢复风扇再收工**（死区热浸泡 104-106°C 先例）
4. SDC 时刻电压/功率记录常设（fail 块 time-at-end 的 UTC now +8h 对齐；严禁 time-to-fail）
5. 单 10min 窗口率不可比；率对比须同温/同构型/同二进制

## 七、未决问题

1. **振动对照臂**（设计已定：恒 F5=20 切 F1-2/F3-4 100↔40）——温度 vs 振动的终审判别
2. **µs 级电压 droop**——BMC 秒级采样物理不可测，需板级仪器才有结论
3. 温度调制机理（时序裕量说）的指令级验证——可结合 -O1/-O2 梯度与 objdump 邻域分析
