# FARRON 性能验证报告（2026-10-25，5 小时在线评估）

**问题（用户）**：逐核暂停应用 15s 测试的方案能否检出本机 SDC？多久检出？FARRON 整体性能如何？
**验证环境**：stress-ng v0.22.01（191 worker 于可靠池 0-178,180-191，排除已知缺陷核 179）作为"用户应用"持续满载；FARRON 逐插槽独占轮扫（应用迁出整插槽 → 48 核测试 → 恢复）；全扇 100%；98°C 看门狗在岗。
**数据**：`farron/state/sweep/eval5h/`（sweeps.csv 588 窗、fail_times.csv、app_cpu.csv 1220 样本、147 份检出轮 stdout）；温度全程 5s 采样。

## 一、方案裁决（三构型对照实验，11:01-11:12）

| 测试构型 | 179 上结果 | 结论 |
|---|---|---|
| 单核独占（原方案：逐核暂停 15s） | 330s（10×15s+3×60s）**零检出**（迭代正常执行：130 块/15s） | ❌ 单核探针构型被负载类型门控关死（同中午实验"探针+movbe 背景=0"） |
| socket 分时（不暂停） | 2×30s 零检出 | ❌ 47/48 核与 stress-ng 分时，时序配方被打断 |
| **整插槽独占（修正方案）** | 每窗均检出 | ✅ **生产形态端到端 128 秒**（CPU1/2/3 干净→CPU4 第 127s 抓到 3 fail） |

**结论：逐核方案在本机不可行，逐插槽独占方案可行且首轮即检出。** FARRON 的在线测试模式应为"逐插槽"粒度（暂停粒度=插槽，测试粒度=插槽 48 核单进程）。

## 二、5 小时连续评估核心指标（147 轮 × 4 插座 = 588 窗）

### 1. 检出能力（灵敏度）

| 指标 | 结果 |
|---|---|
| 逐轮检出率（30s 窗 + 框架自然 ≤1 迭代过冲，实际 21-41s） | **147/147 = 100%** |
| 严格 30s 内首失败 | 111/147 = 76% |
| **15s 窗（用户原规格）首失败** | **52/147 = 35%** ⚠️ |
| 首失败时序 | min 3.7s / 中位 18.5s / max 40.7s（宽分布，非固定冷启动模式——早前"0-3s 必触发"系提取锚点 bug，已修正） |
| 每窗 fail 数 | 1-8，均值 3.19，总计 469 |
| 期间 179 活跃度 | ≈4.7 fail/min（中强度；潜伏期 2/min 时 30s 窗检出率将降至 ~63%，爆发期 ~100%） |

**窗口长度建议**：15s 单窗检出率仅 35%（5 轮累积 ~90%）；**30s 为最小可靠窗口**（本状态下 76-100%）；要求单窗 ≥95% 需 ~60s。FARRON 的温度-时长分配档（60/120/300s）全部满足。

### 2. 误报率（特异性）

清洁插座 CPU1/2/3 共 **441 窗零误报**（特异性 100%），全部 469 次 fail 无一例外锁定逻辑核 179。

### 3. 对应用的影响

| 节奏 | 吞吐保持率 |
|---|---|
| 本次评估（近乎背靠背连续轮扫，扫描占空 ~96%） | **76.0%**（实测 18,299s CPU 时间积分；理论 78% 吻合） |
| 生产节奏推算（每 30min 一轮 2.2min 扫描） | **~98.2%** |

单窗代价：应用瞬时失去 48/191 核（25%）× ~32s；对 stress-ng 类吞吐负载无害，对时延敏感应用需按核分配暂停窗口。

### 4. 热与安全

评估期间峰温 CPU1=82 / CPU2=78 / CPU3=68 / CPU4=65°C（均值 81.0/76.6/66.7/56.8），看门狗零触发，无 panic，stress-ng 全程存活。

## 三、FARRON 性能验证总结

| 验证项 | 规格/预期 | 实测 | 判定 |
|---|---|---|---|
| 端到端检出时间 | 越快越好 | **128s（首轮扫到缺陷插槽）** | ✅ |
| 单窗检出（30s） | 高 | 76-100%（随 179 爆发/潜伏态） | ✅ |
| 单窗检出（15s 原规格） | — | 35% | ⚠️ 建议改为 ≥30s |
| 误报 | 0 | **0/441** | ✅ |
| 缺陷定位 | 精确到核 | **100% 锁 179** | ✅ |
| 应用开销（生产节奏） | 低 | ~1.8%/30min 周期 | ✅ |
| 热安全 | 无越界 | 峰 82°C，零看门狗 | ✅ |

**修订项（已同步 FARRON 设计）**：①在线测试粒度 = 插槽（逐核方案被门控否定）；②窗口下限 30s（15s 检出率不足）；③暂停机制 = taskset 全 worker 迁移（fork 型应用逐进程改亲和）。

## 四、附带科学收获

- **负载类型门控再证**：单核探针 + stress-ng 背景 = 0（第三种被门控关死的背景类型，与 movbe 背景同类）
- **插槽独占构型跨背景鲁棒**：stress-ng 满载 146 核背景下，插槽 48 核测试照常触发（128s 检出）——修正了"需要全机安静"的顾虑，只需**本插槽安静**
- 5 小时新增 179 号 SDC 样本 469 个（全部插槽独占构型，可作签名分析素材）
