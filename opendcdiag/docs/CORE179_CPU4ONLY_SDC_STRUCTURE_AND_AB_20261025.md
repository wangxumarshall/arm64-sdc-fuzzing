# CORE179 CPU4-only 负载结构实验与温度-SDC 终审（2026-10-24/25）

承接 `docs/CORE179_FAN_MAPPING_SCAN_20261024.md`（风扇映射与混合负载热扫描）。本文档归档 CPU4-only 阶段的三大发现与全部数据。

## 一、SDC 触发的插槽自足性（结构发现）

**问题**：只用 CPU4 的核（144-191 共 48 核，含 179）跑 neon_rot_ldr_at_top_rowmajor、其余 144 核全空载，SDC 频率会变吗？

**答案：不变。**

| 负载结构 | SDC 率 |
|---|---|
| CPU4-only 48 核（全扇 100%，52-53°C），30min 定长 | **447 次 = 14.9/min，全 179** |
| 全机 168 核（10-23 16:06 轮） | 15.4/min |
| 混合 72 movbe + 96 neon | 6-12.7/min（漂移） |
| 179 独立进程 + 164 核背景（10-23 中午） | 1.57/min |

- **触发 179 不需要全机并发压力，也不需要其他插槽任何负载**——"系统级压力必要条件"收窄为**插槽/进程级**（179 + 同插槽同测试兄弟线程，单进程）
- 对照中午实验（1.57/min）提示"同进程共振"可能是率的重要变量（179 在进程内 vs 独立进程差 ~10 倍），归因未定
- **以后采 SDC 样本只需 CPU4-only 48 核配置**：风险最低（无其他插槽过热问题）、产率持平最高档

## 三、温度-SDC 率假说的同夜终审：证伪

同一进程 CPU4-only 负载（22:08:55 起）跨三次风扇状态：

| 时段 | 配置 | CPU4 | 率 |
|---|---|---|---|
| 22:19-23:39（80min） | 热档 | 61-64°C | 1.9-3.5/min 潜伏 |
| 23:39-23:49 | 热档末尾 | 61-64°C | 7.4/min **爆发起始** |
| 23:49-23:59 | ~23:50 切全速 | ↓11°C | 14.8/min 峰值 |
| 23:59-00:09 | 全速 | 52.7°C | 12.7/min |
| 00:09-00:19 | ~00:10 切回热档 | ↑11°C | 3.8/min 消退 |
| 00:19-01:20（60min） | 热档 | 63-64°C | 1.2-2.2/min 潜伏 |

**决定性证据：爆发起始于热档、横跨 11°C 降温台阶持续加速、终止于热档恢复**——若温度（或风扇状态）驱动率，切换点应出现阶跃；实际率的演化完全无视切换。此前"52°C 高率 vs 63°C 低率"的表观负相关为爆发时序巧合。

**爆发统计**（3 小时窗口）：单次爆发，时长 ~35min，峰值 14.8/min（潜伏 ~7 倍），积分 ~250 次；潜伏基线 1.2-3.5/min。

**结论**：179 的触发率由爆发/潜伏周期主导，与温度、风扇状态、全机负载均无关。与历史全部证据闭环（8h 恒配置率漂移 12.5→4.8→12.2、热震荡战役四检验、45-73°C 平坦、30min 全核 15.4 vs 混合 6-12 等）。

## 四、方法学沉淀

1. **单 10min 窗口率不可比**（潜伏 2 vs 爆发 15）；跨配置比较需 ≥1h 或多窗口交替
2. **time-to-fail 字段非墙钟**（N 块 2-30s / R 块 38-980s ≫ 块跨度 20-1020ms）——事件时刻用失败块 [start,end]
3. 满载类实验必带 98°C×2 看门狗（本战役三次按设计保护：#14 极限档、17:05 CPU1 扑空、全程零真损失）
4. Bash sleep 上限 600s；监控脚本用绝对路径
5. 风扇扫描协议：每档等 ≥10min 取末 5min 稳态（steady_states.txt 逐档追加）
