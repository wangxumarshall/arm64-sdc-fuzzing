# CORE179 温度研究专档 v2：六风扇效率 · 对应温度 · 179 SDC 频率（2026-10-27）

**定位**：温度轴研究的专门登记册（living 文档）。**记录格式（用户指定）：六风扇的效率 → 其对应的 179 温度 → 该温度下的 SDC 频率。** 新实验结果追加至 §一 各表与 §七 变更记录。
**当前总判决（2026-10-27 晚，证据升级）**：179 的 SDC 基线率**严格跟随其本座（CPU4 插槽）温度**——单调负相关：**52-53°C → ~13/min（23.0 fail/千迭代块）vs 61-64°C → ~1.8-2.8/min（3.1-5.0/千块），~4.6-7.4×**。相位/时序解释已被相邻窗口对照排除（§一 表E-7/8/9）；**唯一剩余混淆 = 温度与风扇耦合物理量（振动/气流）的分辨**——所有变温都经风扇实现，需振动对照臂（§五）。
**速查**：率≈每 +3.5°C 减半；实验下限 52.7°C（全扇 100%+负载），持续上限 63.7°C（F5=20%）；吞吐全程平坦（排除降频伪影）。

## 二、平台热学事实（实验前提）

1. **温度唯一通道**：BMC/IPMI 插槽级（`sudo ipmitool sensor reading ...`，~0.8s/次），无 per-core 温度；179=CPU4_TEMP（socket3=cores 144-191）
2. **无 DVFS**：恒 2.6GHz；SDC 率非降频伪影（两役块吞吐 479-575/min 全平坦）；PROCHOT 期率不变（1.07 vs 0.99/min，频率轴无信息）
3. **热时间常数**：CPU4 对负载 τ≈60-90s；对风扇换档分钟级（23:45 全开 63.7→52.7 约 2-3min 内完成；08:52 恢复 64→54 约 1min）
4. **179 本座特殊性**：CPU4 全机散热最好（同负载比 CPU2 低 ~20°C）；空载 47-48°C 即实验下限；持续上限 63.7°C
5. **操作规程**：每档等 ≥10min 取末 5min 稳态；监控脚本 `taskset -c 0`；看门狗 98°C×2 杀 opendcdiag 全程在岗

## 三、风扇安全红线（做温度实验必读）

1. **F6=40 → CPU1 空载 102°C**（10-24 17:05 看门狗扑空实证）——动 F6 前必查 CPU1
2. **F5 压低必须配 F3-4=100**（F5 与 CPU2 共享风道：#6 中 CPU2=91.9；#14 极限档 CPU2 从 70 冲 98 仅 <5min，13.5h 战役被看门狗终结）
3. **CPU4-only + F5=20 + F3-4/F6=100 = 唯一干净加热构型**（CPU4 63.7°C，CPU1/CPU2 安全）——表B1 即此构型
4. **降风实验结束必须先恢复风扇再收工**（死区下 CPU2 停转热浸泡 104-106°C）
5. 教训：FAN_CHANGE 记录可能滞后实际换档（23:45 的实际降温被记成 23:57）——**换档时刻以温度曲线/功耗拐点为准**，本专档表E 已全部用温度拐点校正

## 五、当前机理判断与剩余判别

- **已排除**：相位/时序（表E-6/7/8）；吞吐/降频（块率平坦）；负载类型门控（两役负载恒定）；机位热度（#13 vs #8 消歧：CPU2 同凉率差 1.9×）；**供电电压（2026-10-29 直接测量：主核轨恒 0.96V 无压降、SDC 时刻电压分布与负载期一致，不偏好低压时刻——见 `docs/CORE179_VOLTAGE_AT_SDC_20261029.md`；µs 级瞬态 droop 为不可测残留）**
- **候选（二选一，现有数据不可分）**：①**硅温度直接调制**——机理候选为时序裕量：冷硅路径更快 → str→ldr 转发窗更紧 → L1D 读路径错更多（与触发配方对时序的极端敏感性自洽：nop≥8 灭活、编译期布局敏感）；②**风扇耦合物理量**（振动/气流/声学）——所有变温均经风扇实现，凉窗=全扇 100%（振动最大）恰为高率窗，两说方向都符合 09-11"重启 3/5 在最凉条件"
- **弱分离证据**：表D 五次单扇换档（振动变化不小、温度不动）无一致率响应——轻微不利于振动说，但单扇振动增量不足以定案
- **判别实验（振动对照臂）**：CPU4-only 恒 F5=20（CPU4 钉 63.7°C），仅切换 F1-2/F3-4 在 100↔40 间大幅变化（转速大变、CPU4 仅 −1.5~−2.6°C）——**率跟转速走 → 振动说；率不动 → 温度说定案**。辅臂：F5 100↔20 随机交错 ≥4 轮复现表B1 关系
- 文献（CACM 2026-09 综述）：温度是典型触发条件，方向不可直觉预判
